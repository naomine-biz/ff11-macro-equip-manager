# ff11-macro-equip-manager

FINAL FANTASY XIのローカルファイルから、マクロ・装備セット・持ち物を確認し、装備セットの参照位置を補正するWindowsデスクトップアプリ。

Python 3.12の標準ライブラリとTkinterで動作します。インストール済みのFF11のローカルファイルを読み取ります。

## 現在できること

- キャラクターフォルダごとにマクロの各行、装備セット、全17収納の持ち物を表示。
- ローカルのゲームリソースからアイテム名・アイコン・定型文を表示。
- マクロから空の装備セットへの参照と、マクロ参照のないセットを一覧表示（読み取り専用）。
- 装備枠を「一致」「Fix可能」「候補が複数」「候補なし」で表示。詳細から根拠を確認。
- 種類IDが全持ち物で一意な場合、参照位置の補正案を作成。
- マクロの `/equip` とインベントリを照合し、収納番号の追加・変更案を表示。
- マクロ名・6行の個別編集、マクロと装備セットのFixを作業データに適用。
- 共通のUndo／Redoと、作業ファイルへの自動保存・再開。
- ワードローブ1〜8の、/equipと全装備セットから参照されていないアイテムを一覧表示。
- キャラクターの表示名をアプリ側に登録。

個体別オーグメントの取得は未対応です。装備セットの移動・コピー、移動時のカスケード更新、マクロの任意編集をゲームへ保存する機能は今後実装します。

## 起動

Python 3.12（Tkinterを含む）をインストールし、リポジトリ直下で実行します。

```powershell
python reader.py
```

`start.cmd` からも起動できます。レジストリからインストール先を検出できない場合や複数ある場合は指定します。

```powershell
python reader.py --root "C:\path\to\FINAL FANTASY XI"
```

キャラクターと表示モードを選び、左の一覧から対象を選択します。装備枠をクリックすると状態と根拠が表示されます。

## 編集と作業保存

1. マクロを選び「選択マクロを編集」で名前・各行を入力します。
2. 「変更案を確認」で差分を確認し、作業データに適用します。
3. 「マクロの収納番号を確認・補正」から、選択マクロまたはキャラ全体の収納番号Fixを確認できます。
4. Undo／Redoで操作を戻す・やり直すことができます。一括Fixは1操作です。

画面は編集バッファを表示し、変更を `work/drafts/<インストール識別子>.json` に自動保存します。作業ファイルにはマクロなどの個人データが含まれます。`work/` はGitの管理対象から除外しています。

再起動すると作業と履歴を復元します。元のゲームファイルが変わっている場合は、以前の作業ファイルを保管して新しい編集を開始できます。「作業ファイルを保管して編集をリセット」で履歴を保管し、今回読み込んだ状態に戻せます。

## 装備セットの補正をゲームへ保存

1. 対象キャラクターを選び、「装備セットの参照位置を補正」で変更案を確認してアプリ内へ適用します。
2. 「装備セットの補正をゲームに保存…」で、セット番号・名前・枠・アイテム・収納と位置の変更前後・対象ファイルを確認します。
3. FF11とPlayOnlineを終了し、「バックアップして…枠をゲームに保存」を押します。
4. 完了欄に保存・検証結果とバックアップ先を表示します。ゲーム内で対象セットを確認してください。

保存するのは、選択キャラの編集バッファに適用済みで、全収納を再照合して一意に決まる参照位置の補正です。その他の装備セット編集は作業データに保持し、件数を表示します。マクロの編集も保持します。保存後もUndo／Redoを使えます。

全対象の原本と差分記録を `backups/equipment/<保存ID>/` へ保存・検証してから書き込みます。複数ファイルの途中失敗は、今回の保存内容と一致するファイルを原本へ復元します。中断時はバックアップとpending記録を保持し、再起動時に状態を確認します。Program Filesへの権限が不足すると保存を中止します。必要な場合は管理者権限でアプリを起動し、プレビューを開き直してください。

復元は、FF11とPlayOnlineを終了して以下を実行します。最初のコマンドで全対象を検証し、`--apply` で復元します。別の変更が見つかった場合は復元を保留します。

```powershell
python restore_equipment.py "backups/equipment/<保存ID>"
python restore_equipment.py "backups/equipment/<保存ID>" --apply
```

## マクロの収納番号Fixをゲームへ保存

1. 収納番号Fixを作業データへ適用します。
2. 「マクロの収納番号をゲームに保存…」で、選択キャラの保存対象行・変更前後・対象ファイルを確認します。
3. FF11とPlayOnlineを終了し、「バックアップして…行をゲームに保存」を押します。

現在の候補で一意に決まる収納番号Fixを保存します。その他のマクロ編集は作業データに保持し、件数をプレビューに表示します。元の定型文・装備名・waitなどをバイト単位で保持し、番号部分とチェックサムを更新します。番号追加で60バイトを超える行がある場合は保存プレビューで知らせます。

保存前にマクロ・全収納・辞書のハッシュと候補を再確認します。全対象の原本と差分記録を `backups/macros/<保存ID>/` に保存してから置換し、保存後に全バイトと形式を検証します。途中失敗時は書き込んだファイルを復元します。強制終了・停電などで処理が中断された場合は、receipt.jsonと作業ファイルのpending記録を使って復旧を確認します。

保存後もUndo／Redoは編集バッファに反映されます。現在の保存済み状態との違いを「変更あり」で示します。作業ファイルの同期が中断された場合は次回起動時にゲームファイルのハッシュを照合して再開します。

Program Files配下への保存には管理者権限が必要な場合があります。権限不足時は保存を中止します。GUIでプレビューを確認してから、必要に応じて管理者権限の端末で同じ作業ファイルを保存できます。

```powershell
python save_macro_fixes.py --character <フォルダID>
python save_macro_fixes.py --character <フォルダID> --apply
```

バックアップからの復元は、以下のプレビューと適用コマンドで行います。保存後に別の変更がある場合は復元を保留します。FF11とPlayOnlineを終了した状態で実行してください。

```powershell
python save_macro_fixes.py --restore "backups/macros/<保存ID>"
python save_macro_fixes.py --restore "backups/macros/<保存ID>" --apply
```

既存の装備セット保存・復元CLIも独立した機能として残っています。

## 実機での保存確認

2026-10-27、装備セットの参照位置147枠を9ファイルへバックアップ付きで保存。9ファイルすべての保存結果と原本バックアップのハッシュ一致、保存後検証の完了を確認しました。ユーザーがゲーム内で装備セットの動作に問題がないことを確認しました。

2026-10-27、52マクロ・59行を12ファイルへバックアップ付きで保存。再読込で59行すべての参照一致、対象外1,857ファイルのハッシュ維持を確認しました。ゲーム内でも、保存対象の1行に収納番号が追加されていることをユーザーが確認しました。実データとバックアップはPC上で保管しています。

## テスト

```powershell
python -m unittest discover -s tests -v
```

通常は合成データのテストを実行し、実機GUIテストはスキップします。インストール済みFF11を読み取るGUIテストは明示的に有効化します。

```powershell
$env:FF11_RUN_INTEGRATION = "1"
python -m unittest discover -s tests -v
```

書き込みテストには一時ファイルを使用します。
