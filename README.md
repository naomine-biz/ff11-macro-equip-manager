# ff11-macro-equip-manager

FINAL FANTASY XIのローカルファイルから、マクロ・装備セット・持ち物を確認し、装備セットの参照位置を補正するWindowsデスクトップアプリ。

Python 3.12の標準ライブラリとTkinterで動作します。インストール済みのFF11のローカルファイルを読み取ります。

## 現在できること

- キャラクターフォルダごとにマクロの各行、装備セット、全17収納の持ち物を表示。
- ローカルのゲームリソースからアイテム名・アイコン・定型文を表示。
- マクロから空の装備セットへの参照と、マクロ参照のないセットを一覧表示（読み取り専用）。
- 装備枠を「一致」「Fix可能」「候補が複数」「候補なし」で表示。詳細から根拠を確認。
- 種類IDが全持ち物で一意な場合、参照位置の補正案を作成。
- 選択した装備セットの自動補正をプレビューし、バックアップ付きで保存・復元。
- キャラクターの表示名をアプリ側に登録。

個体別オーグメントの取得は未対応です。マクロ編集、装備セットの移動・コピー、移動時のカスケード更新は今後の機能です。ゲームへの保存は装備セット単位で行います。

## 起動

Python 3.12（Tkinterを含む）をインストールし、リポジトリ直下で実行します。

```powershell
python reader.py
```

`start.cmd` からも起動できます。レジストリからインストール先を検出できない場合や複数ある場合は指定します。

```powershell
python reader.py --root "C:\path\to\FINAL FANTASY XI"
```

キャラクターと表示モードを選び、左の一覧から対象を選択します。装備枠をクリックすると状態と根拠が表示されます。

## 自動補正の保存

1. 保存が完了するまでFF11とPlayOnlineを終了した状態にします。
2. 対象の装備セットを選び「選択セットの自動補正をゲームに保存…」を押します。
3. 対象アイテムと位置の変更案を確認して保存します。

保存は1個の装備セットファイルに限定します。元ファイルと全収納がプレビュー時から変わっていた場合は中止します。元ファイルを `backups/<保存ID>/original.dat` に保存してから置換し、書込後に検証します。Program Files配下などでは管理者権限が必要です。権限不足時は保存を中止します。

「直前のゲーム保存を復元…」で戻せます。アプリ再起動後の復元は以下を使用します。

```powershell
python save_reference.py --restore "backups/<保存ID>" --apply
```

保存後にゲームファイルが変更されていれば復元を拒否します。既存の「アプリ内に適用」は下書き操作で、ゲームへの保存とは別です。下書きのFixは取り消してからゲーム保存へ進みます。

補正後はゲーム内の装備セット表示で参照先を確認します。ゲーム側には保存位置がずれたアイテムの代替検索があります。確認済みの範囲は、初期開発環境での1枠の保存・再読取・ゲーム内表示です。

## テスト

```powershell
python -m unittest discover -s tests -v
```

通常は合成データによる52テストを実行し、実機GUIテスト1件はスキップします。インストール済みFF11を読み取るGUIテストは明示的に有効化します。

```powershell
$env:FF11_RUN_INTEGRATION = "1"
python -m unittest discover -s tests -v
```

書き込みテストには一時ファイルを使用します。
