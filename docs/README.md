## 更新手順

1. 対象の要件IDと設計条件IDを確認する。
2. 動作または責務を変更する場合は正本を先に更新する。
3. 検証仕様・コード・実行可能なテストを正本に合わせる。検証仕様の存在とテストの実装・成功を区別する。
4. 対応表を更新する。未決定の動作は要件で確定してから実装する。

具体的な型・クラス・メソッドはコードで管理する。形式上の事実は調査資料に記録する。検証仕様と正本に相違があれば正本を確認して解消する。
