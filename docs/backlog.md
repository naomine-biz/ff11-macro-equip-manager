# バックログ

- 個体別オーグメントを既存ローカルファイルから取得する。現在は保留。取得方法は既存ローカルファイルの調査を前提とする。
- マクロ・装備セットの編集、キャラ間コピー。
- パレット・マクロ・装備セット移動時の参照カスケードと事前プレビュー。
- マクロのタイプミス・曖昧なアイテム参照などの通知。
- 複数アカウント・キャラの整理。

現在の保存経路は、装備セット単位の参照補正と、選択キャラのマクロ収納番号Fixに対応する。

- マクロの任意編集をゲームへ保存。新規テキストと定型文のエンコード、収納番号Fix以外の変更の保存方針。
- ゲーム側変更時の編集差分の選択的な引き継ぎ。
